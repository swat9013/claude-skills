# 呼び出し元向けの反映の契約

他の skill が、承認済みの変更を本 skill に書かせるときの呼び出し口。決めるのは、渡す args・invoke の回数・反映を終えられなかったときの返し方の 3 点だけ。何を書かせるか (候補・証拠・invoke 時に添える制約) と、反映の前後に呼び出し元が通す確認は、呼び出し元の手順が持つ。

## 渡す args

- 反映先が既存の file なら、その path 1 本を渡す
- まだ存在しない file を起こすなら `新規: <component> <目的>` を渡す。存在しない path を渡すと、本 skill の手順 1 が対象 file を解決できない
- args にはこの 2 形のどちらかだけを置く。反映する内容 (候補・証拠・反映案) と呼び出し元の制約は、invoke 直前の同一 turn のテキストで宣言する — 同じ context に載ったまま本 skill へ渡るので、args に足す必要はない

## invoke の回数

- 1 回の invoke で書き換わる範囲は本 skill の手順 1 の「書き換える対象は広げない」が決め、args の file を超えない。反映先 file 1 本につき 1 回 invoke する。2 file にまたがる変更 (移動先への追加と元 file の行削除など) は、file ごとに 1 回ずつ invoke する
- 新しい `.claude/rules/<topic>.md` を起こし、対象 repo の CLAUDE.md が rules の索引表を持つなら、CLAUDE.md を args にもう 1 回 invoke して索引行を足す。この 1 回を省くと、新しい rules が索引に載らないまま反映が終わる

## 反映を終えられなかったとき

本 skill が反映を完了せずに終わったら、本 skill が返した停止理由と復旧の案内を、呼び出し元はそのまま伝える。解釈も再記述もしない — 停止の検知と案内は本 skill が持つので、言い換えると復旧に要る情報が落ちる。
