# 同じ会話での再 invoke

読み始める前に、同じ会話の前回の invoke が手順 2 で引いた HEAD と status、読んだ規範の本文、規範を引いた鍵 (変更対象 path と ADR の grep に使った語) が context に逐語で見えているかを確かめる。見えていて、今の HEAD が前回と同じで、前回と今回の status (同じ引数で引く) がどちらも空なら、対象 repo の規範は読み直さず前回の本文を使う。今回の issue (書き換え案があればその文面) から引いた鍵のうち前回に無いものだけを、SKILL.md 手順 2 の「issue の変更対象から引くもの」で読み足す — 鍵が同じなら当たる規範も同じで、鍵が増えた分だけ当たる規範が増えうる。plugin 同梱の基準は対象 repo の HEAD と status では変更を捉えられないので、使い回さずに読む。前回の値か本文が context に逐語で見えない (前回の invoke が同じ会話に無い・compaction で要約された等) か、HEAD か status を引けないときは、条件を確かめられないので全部読む。使い回したときも、出典は前回読んだ規範と今回読んだ規範に限り、context に残った前回の本文の file:line をそのまま出典にする。
