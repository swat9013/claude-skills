# 人手の作業のコメント

issue-triage の SKILL.md §6 で、区分 4 (人手) の issue へ投稿するコメントを書くときに読む。

中身は停止理由 (どの操作がなぜ人手でしか進まないか)・そこまでに残した成果・人が次に実行する手順の checklist (`- [ ]` の行。最後の行は「作業を終えたら、その旨と結果を新しいコメントに書き、`ready-for-human` を外して `needs-triage` を付ける」で、label は対象 repo の綴りで書く — label を外さないと作業を終えた issue がどの queue にも戻らず、コメントが無いと次の triage が新しい情報を見つけられず同じ 4 (人手) で返す)
