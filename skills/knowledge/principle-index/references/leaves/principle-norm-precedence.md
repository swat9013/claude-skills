# 食い違う規範は、適用範囲と日付で裁く

- **適用範囲を絞った個別の規範 (特定の path・component・手順・機構だけに掛かるもの) が、全体に掛かる一般の規範に勝つ**。個別の規範は、一般の規範が当たる場面のうちその範囲だけを別に決めるために書かれるので、一般の規範を勝たせると個別の規範が当たる場面が残らない
- **2 つとも決定記録 (ADR など、日付を持つ決定の記録) なら、日付の新しい方が勝つ**。新しい記録は古い記録の後に、それを踏まえて決められている
- **設計 doc は、その適用範囲に絞った規範として扱う**。repo 全体に掛かる規範と食い違っても、範囲の基準で必ず負けることは無い
- **優先順位で決まらない衝突は裁定せず人へ返す**。範囲の基準と日付の基準が逆の規範を勝たせるとき (範囲を絞った古い決定記録と、一般の新しい決定記録など)、どちらの基準も当てはまらないとき (同じ範囲に掛かり、決定記録どうしでもない) がこれに当たる — どちらを勝たせても、書いた人の意図を agent が推測で決めることになる
