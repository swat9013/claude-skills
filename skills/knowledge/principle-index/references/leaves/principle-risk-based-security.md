# 検査は前倒し、投資はリスクベース

- **検査は開発初期工程へ前倒しする** (shift left — SAST / code review / pre-commit 段階での検出。早期発見ほど修正コストが低い)
- **検査の置き場はまずローカルの commit / push hook にする**。hook は commit 前に検出でき、前倒しの最前段に当たる。ホスト型 CI の利用にコスト制約があるなら、ホスト型 CI は hook で代替できない工程 (リリース等) だけに使う
- **投資はリスクベース**: 資産価値と脅威モデルに基づいて配分する。一律の最大防御にしない
