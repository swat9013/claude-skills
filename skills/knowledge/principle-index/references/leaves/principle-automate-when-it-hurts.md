# 痛みの実測後に自動化し、遵守は機械で保証する

- **Automate When It Hurts**: 反復作業の自動化は、痛み (反復コスト) の実測前にしない (規約遵守の機械化は次項)。自動化を提案するときは痛みの根拠を添える (= いつ自動化するか)
- **遵守は機械で保証する**: 規約の遵守を人の注意力に頼らない。決定的に判定できる制約 (索引と本文のような記述の同期・層や範囲の境界を含む) は、痛みの実測を待たずに既定で lint / hook / 型・構造で守らせる。誤検知が実害になるときだけ散文で守り、機械にしない理由を規約の側に 1 句で残す。遵守が難しい表現形式 (手書きの TAB 区切り等) は最初から選ばない (= どう守らせるか。上の規則とは別軸)
- **決定的にできる推論は script へ追い出す**: LLM 推論のうち決定論的に書ける部分は script 化する (テスト可能・トークン削減)。実現手段は非標準の拡張より標準機能内での実現を優先する
